# Scientific Draw Odds: website

This repository holds the source for [scientificdrawodds.com](https://scientificdrawodds.com). The site is built with [Quarto](https://quarto.org) and published to GitHub Pages automatically by `.github/workflows/publish.yml` whenever a change reaches the `main` branch.

The model that produces the odds lives in a separate private repository. This repository contains only what the site publishes.
